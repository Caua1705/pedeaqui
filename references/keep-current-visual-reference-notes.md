# Current Visual Reference Notes

The restaurant UI was extracted from the existing Júnior da Picanha page to preserve behavior and visual continuity.

Keep these interaction expectations while continuing the split:

- mobile-first white ordering UI;
- centered restaurant name in the navbar;
- search action on the right;
- category tabs above product results;
- product cards with text left and image area right;
- sticky cart bar only with items;
- cart, checkout, submitted order and profile screens intact.
